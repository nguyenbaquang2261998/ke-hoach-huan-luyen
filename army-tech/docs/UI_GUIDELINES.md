# UI Guidelines

Framework chính:
- Next.js
- Tailwind CSS
- shadcn/ui
- lucide-react

Quy tắc:
- Ưu tiên dùng component shadcn/ui.
- Giao diện chuyên nghiệp, hiện đại, tối giản.
- Không dùng màu quá sặc sỡ.
- Layout phải responsive.
- Không phá vỡ logic nghiệp vụ hiện có.
- Tách component rõ ràng.
- Tên component dễ hiểu.
