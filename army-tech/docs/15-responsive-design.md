# Responsive Calendar

Module lịch tuần:

* Desktop: panel trái, lưới tháng, panel chi tiết đặt cùng hàng
* Tablet: lưới tháng ưu tiên hiển thị trước, panel xếp dưới
* Mobile: lưới 7 cột cuộn ngang để giữ cấu trúc ngày/tuần
* Chế độ ngày trên mobile hiển thị dạng agenda một cột
